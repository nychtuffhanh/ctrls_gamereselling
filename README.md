# CTRL S — Myanmar Game Buying Marketplace

Front-end only HTML/CSS/vanilla JavaScript marketplace.

## Updated version
- Buying-focused UI; no game-selling workflow
- 20 requested game titles
- Prices in Myanmar Kyat, from 5,000–50,000 MMK
- Search, category/platform filtering and sorting
- Product detail pages
- Functional cart, quantity controls and automatic price calculation
- Subtotal + 2% service fee + 1,500 MMK demo delivery fee
- Wishlist and localStorage
- Login/sign-up demo
- Telegram, Viber, phone and email contact details
- `assets/images/game-01.jpg` through `game-20.jpg` are intentionally empty image slots. Replace them with your own licensed game images.

## Open
Open `index.html`, or use VS Code Live Server.
